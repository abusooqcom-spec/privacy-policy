Ruler Grid - Privacy Policy

Last Updated: 16.04.2026

This Privacy Policy describes how we collect, use, and share user data. By using Ruler Grid, you agree to the terms of this Privacy Policy.

1. Data Collection

User Activity

The extension's core function requires it to handle user activity only when it is active. This includes:

  • Mouse Position & Clicks: To know which element you are hovering over or selecting for inspection.
  • Scroll Events: To ensure overlays stay correctly positioned while scrolling.

This data is used only locally in real-time and is never stored, logged, or transmitted.

Website Content

To function as an inspector, the extension may read page content when activated:

  • DOM & CSS: To display structure and styles.
  • Text & Image URLs: For inspection and export via side panel.

This data is only read and displayed locally. It is never stored or transmitted.

Payment Information

We do not collect or store any payment information. Payments are handled by Gumroad.

Note: We do not sell or share personal data with third parties except where required for functionality.
